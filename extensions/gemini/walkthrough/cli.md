## The Gemini CLI

GeminiCode runs the Gemini CLI as its agent. It comes with a tested copy, so this step usually ticks itself off on first launch. It uses the CLI set in `gemini.cliPath`, then a copy you installed from GeminiCode, then the copy that came with it, then `gemini` on your `PATH`.

Want a newer CLI? **Install Gemini CLI** downloads the release from npm, checks it, and keeps it in GeminiCode's own storage. Nothing else on your machine changes.
