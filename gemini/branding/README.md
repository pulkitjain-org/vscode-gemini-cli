# GeminiCode icons

- `icon.svg`: the app icon for Windows, Linux and the web, and `code-icon.svg` in the workbench.
- `icon-macos.svg`: the macOS icon (`resources/darwin/code.icns`), drawn on Apple's icon grid: an 824/1024 tile with continuous corners, a light glass rim and a soft shadow, so it sits level with other apps in the Dock (finish A, picked 3 Oct 2026).

Every raster size is rendered from these files at that size, not scaled down from one large image.
