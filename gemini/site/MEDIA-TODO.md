# Media still needed for the site

Every screenshot and clip in `gemini/site/media/`, except `showcase-console-*` (kept from the earlier build by choice), was taken on 2026-10-19 from the GeminiCode 1.142.0 dev build, in GeminiCode Dark and GeminiCode Light, with the window filling the built-in display at 2x and exported at 2000 × 1250. Each product shot has a `-dark.webp` and a `-light.webp`; `build.mts` shows the one that matches the page's theme.

Capture from the real app, against the demo in `demo/`: never redraw or reuse a shot from this folder for a different purpose. `demo/README.md` says how to set up the demo and take each shot.

## Needed for the feature pages

- `index-page`: the Index page with both workspaces indexed and attached documentation (Agents page).
- `showcase-mr-review` (clip): reviewing a merge request with Gemini and posting the review (Connected tools page).
