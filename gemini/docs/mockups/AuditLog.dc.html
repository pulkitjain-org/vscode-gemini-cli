What a row holds

time · agent id · caller (agent or ui) · tool · hash of the arguments · hash of the approved text · permission outcome and who answered · the remote id the tool returned. Text and arguments themselves are not stored; the transcript has them.

What it proves

Nothing on its own. The remote id joins each row to Jira's issue history or GitLab's merge request activity, which stay the record. The pilot's check is: every row with a result has a matching entry there, and every entry there made from GeminiCode has a row.

After a restart

An intent without a result (the highlighted row) is listed on Home under Unfinished. Re-check reads GitLab first: if the merge request already exists, the row gets its id; if not, the flow reopens at the step it reached.
